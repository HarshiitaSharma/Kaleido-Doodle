# Kaleido Doodle

A tiny drawing toy: draw anywhere and every stroke is mirrored around the center like a kaleidoscope.

One static HTML file. No build step, no dependencies, nothing leaves your browser.

## Features

- Adjustable slices (2 to 20), brush size and hue
- Rainbow mode, mirror mode and glow
- **Surprise me** draws a random looping pattern for you
- Undo (up to 15 steps), clear, and **Save PNG**
- Works with mouse, touch and pen; light and dark UI

## Run it

Open `index.html` in a browser, or host it on GitHub Pages (**Settings → Pages → Deploy from a branch → `main` / root**).
